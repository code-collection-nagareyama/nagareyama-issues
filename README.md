# Nagareyama Issues

流山市のオープンデータ（259データセット）と市議会の議論（2018〜2026年の会議録）を突き合わせて、
**データをもとに描きだした、想定される社会課題**を10枚のカードに整理したサイトです。

## 設計の要点

課題を並べるだけでは、どれから手をつけるかを決められません。
そこで**全カードを同じテンプレート（7ブロック）で書き**、横並びで比較できるようにしています。

| # | ブロック | JSONキー | 決めごと |
|---|---|---|---|
| 1 | だれの、どの場面か | `persona` / `pain` | 困りごとを「いつ・どこで・何に・今はどうしているか」の4点に分解する |
| 2 | 困っている場面 | `scene.panels` | 3コマ固定（いま → ぶつかる壁 → こうしたい）。共通アイコンで描く |
| 3 | ユーザーストーリー | `stories[]` | 〈だれとして / 何がしたい / なぜなら〉。行政側を主語にしたものを最低1本 |
| 4 | 根拠 | `evidence` | オープンデータ / 議会 / 市民の声 の3系統に必ず分ける |
| 5 | 活用のかたち | `solution` | 使うデータ → つくるもの → 届く人 の3段 |
| 6 | どう測るか | `kpi[]` | オープンデータで測れる指標を優先 |
| 7 | 実現度と足りないデータ | `feasibility` | 5段階＋不足データ。**これが市への公開要望のたたき台になる** |

7番の「足りないデータ」欄が、このテンプレートの実用上の要です。
10枚を通して読むと、市のオープンデータに繰り返し欠けているものが見えます。

- **座標がない**（買い物支援協力店・認可保育施設・AED は住所文字列のみ。他の施設データには緯度経度がある）
- **道路データが存在しない**（路線・幅員・歩道の有無・通学路指定。カテゴリ c_03 は2データセットのみ）
- **粒度が款どまり**（一般会計歳出決算は款別。事業別に下りられない）
- **リアルタイム／頻繁更新がない**（施設の空き状況、園の年齢別空き枠）

## リポジトリ構成

```
data/issues.json          全カードのデータ（ここが唯一の情報源）
schema/issue.schema.json  テンプレートのJSON Schema
build.py                  issues.json → docs/ を生成
docs/                     生成物。GitHub Pages の公開ディレクトリ
  index.html              一覧（テーマ絞り込み・並び替え）
  template.html           テンプレート仕様とアイコン集
  sources.html            データ出典と、その扱い方
  issues/<slug>.html      各カードの詳細
  issues.json             カードデータを再利用できるよう配信
.github/ISSUE_TEMPLATE/   GitHub Issue のひな型（カードへの気づき）
```

## 気づきを起票する

各カードの詳細ページから「このカードへの気づきを起票する」を開くと、対象カードが入った [Issue テンプレート](.github/ISSUE_TEMPLATE/card-feedback.yml) が立ち上がります。GitHub の Issue 画面から直接書く場合は、テンプレート「カードへの気づき」を選んでください。

## カードを追加する

1. `data/issues.json` の `issues` に1件足す（`schema/issue.schema.json` に従う）
2. `python build.py`
3. コミットして push（依存パッケージなし・Python 3 標準ライブラリのみ）

`docs/` は毎回作り直されます。`docs/` を直接編集しないでください。
